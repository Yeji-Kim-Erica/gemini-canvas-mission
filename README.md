# gemini-canvas-mission

Gemini Canvas 미션 결과물을 관리하는 저장소입니다.

## 목적

- Gemini Canvas로 제작한 웹앱 결과물을 기록하고 공유합니다.
- 앱별 요구사항, 배포 링크, 회고를 일관된 형식으로 남깁니다.

## 💻 1. 유틸리티 앱 : ✨ 보송 청소 매니저

**자취생과 1인 가구를 위해, 다정하고 똑똑하게 집안일 주기를 관리해 주는 웹 애플리케이션입니다.**

이 앱은 '언제 청소했더라?' 하는 기억의 부담을 덜어주고, 딱딱한 알림 대신 다정한 룸메이트처럼 청소 시기를 챙겨주어 사용자가 스트레스 없이 쾌적한 생활 공간을 유지할 수 있도록 설계되었습니다.

## 🌟 주요 특징

### 1. 직관적인 상태 알림과 다정한 동기부여

- 각 집안일의 남은 주기에 따라 카드의 색상이 부드러운 파스텔톤(임박 시 노란색, 지났을 시 분홍색 은은한 글로우 효과)으로 변합니다.
- 기계적인 명령이 아닌 "슬슬 화장실 바닥이 미끄러워지려 해요. 가볍게 닦아볼까요?"와 같은 친근한 권유 문구로 청소를 기분 좋게 시작할 수 있게 돕습니다.

### 2. 원클릭 기록 및 스마트 주기 계산

- 청소를 마친 후 카드 하단의 **'✓ 완료'** 버튼을 누르면 즉시 완료 기록이 저장됩니다.
- 기록된 날짜를 바탕으로 사용자가 설정한 주기에 맞춰 '다음 예정일'과 '경과일'이 자동으로 계산되어 표시됩니다.

### 3. 나만의 맞춤형 청소 주기 설정

- 사용자의 라이프스타일과 집 크기에 맞춰 화장실 청소, 분리수거, 이불 빨래 등 8가지 기본 집안일의 목표 주기를(일 단위) 자유롭게 수정할 수 있습니다.

### 4. 꼼꼼한 활동 기록(청소 발자국) 및 수정

- **활동 기록 탭:** 전체 로그를 보거나 드롭다운 필터를 이용해 특정 집안일(예: 빨래)의 기록만 모아볼 수 있습니다.
- **기록 수정:** 청소 후 기록하는 것을 깜빡했더라도, 연필 아이콘을 눌러 실제 청소했던 과거의 시간으로 정확하게 수정할 수 있습니다.

### 5. 클라우드 기반 실시간 동기화

- 이메일 계정을 통한 회원가입/로그인 시스템을 제공합니다.
- Firebase를 연동하여 기기나 브라우저가 바뀌어도 나의 청소 설정과 과거 발자국들을 안전하게 불러오고 관리할 수 있습니다.

## 🛠 사용된 기술

- **Language:** 순수 JavaScript (Vanilla JS, ES6 Modules)
- **Markup:** HTML5
- **Styling:** CSS3 (Custom Variables, CSS Grid/Flexbox, Keyframe Animations 적용)
- **Backend/BaaS:** Firebase (Authentication, Cloud Firestore)
- **Font:** Gowun Dodum, Noto Sans KR (Google Fonts)

## 🚀 실행 방법

1. `index.html` 파일을 다운로드합니다.
2. 인터넷이 연결된 상태에서 최신 브라우저(Chrome, Safari 등)로 파일을 엽니다. (Firebase 통신을 위해 인터넷 연결 필수)
3. **가입하기**를 통해 이메일 계정을 생성하고 나만의 청소 주기를 관리해 보세요!

## 🧹 기본 관리 집안일 구성

- **위생 관리:** 화장실 청소
- **쓰레기 관리:** 음식물 쓰레기 비우기, 재활용 쓰레기 분리수거, 일반 쓰레기 비우기
- **공간 관리:** 바닥 청소(청소기/물걸레), 먼지 털기
- **세탁 관리:** 옷 빨래, 이불 빨래

**"보송 청소 매니저와 함께 매일매일 상쾌하고 보송보송한 일상을 만들어보세요!"**

## 📚 3. 학습 앱 : ☕ Java Master Quiz

**Java 기초부터 최신 Java 21 버전의 신기능까지 완벽하게 학습할 수 있는 인터랙티브 퀴즈 애플리케이션입니다.**

이 앱은 초보자부터 고수까지 모든 단계의 개발자가 Java의 핵심 개념과 최신 트렌드를 재미있고 체계적으로 익힐 수 있도록 설계되었습니다.

## 🌟 주요 특징

### 1. 중복 없는 스마트 문제 시스템
* 사용자가 한 번이라도 확인한 문제(정답, 오답, 건너뛰기 포함)는 학습 이력에 실시간으로 기록됩니다.
* 학습 세션을 새로 시작할 때 이미 본 문제는 출제 범위에서 영구적으로 제외되어 항상 새로운 문제를 접할 수 있습니다.

### 2. Java 21 최신 문법 반영
* 전통적인 Java 문법은 물론, **Sequenced Collections, Virtual Threads, Sealed Classes, Record** 등 최신 Java 21 버전의 핵심 기능들을 퀴즈를 통해 학습할 수 있습니다.

### 3. 맞춤형 난이도 필터
* **초보 / 중수 / 고수 / 전체** 4가지 모드를 제공하여 자신의 현재 실력에 맞는 문제를 선택해 풀 수 있습니다.
* 각 난이도별 정복 상태를 대시보드에서 실시간으로 확인할 수 있으며, 마지막으로 선택한 난이도가 자동으로 저장됩니다.

### 4. 고도화된 오답노트 및 학습 관리
* **대시보드:** 정답 개수와 오답 개수를 한눈에 파악합니다.
* **내역 확인:** 상세 리스트를 통해 정답과 해설을 토글 형식으로 다시 복습할 수 있습니다.
* **오답 팝업:** 틀린 문제만 모아 팝업창에서 다시 풀 수 있으며, 한 번에 맞춘 문제는 자동으로 오답 내역에서 삭제됩니다.

### 5. 사용자 친화적 UI/UX
* Java 테마(Blue & Orange)를 반영한 모던하고 깔끔한 디자인.
* 모든 문제를 정복했을 때 나타나는 특별한 축하 모달과 "Coming Soon" 안내 시스템.
* 브라우저 기본 알림 대신 일관성 있는 커스텀 모달 팝업 적용.

## 🛠 사용된 기술

* **Language:** 순수 JavaScript (Vanilla JS)
* **Markup:** HTML5
* **Styling:** CSS3 (Custom Variables, Flexbox, Grid 활용)
* **Font:** Noto Sans KR (Google Fonts)
* **Dependencies:** 외부 라이브러리나 프레임워크 없이 순수 기술로만 구현되어 가볍고 빠릅니다.

## 🚀 실행 방법

1. `index.html` 파일을 다운로드합니다.
2. 최신 브라우저(Chrome, Edge, Safari 등)에서 파일을 엽니다.
3. 난이도를 선택하고 **학습 시작** 버튼을 눌러 Java 마스터가 되어보세요!
